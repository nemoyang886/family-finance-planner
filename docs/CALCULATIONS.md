# 计算口径 MVP 0.4

所有金额统一使用“万元”，收入和支出使用“万元 / 年”。当前版本只做确定性计算，不调用 AI 推测家庭事实。报告参考“三个阶段目标”组织讲解：

1. 财务安全：先保证必要生活与家庭风险应对；
2. 财务独立：让收入能够覆盖支出，并形成持续结余；
3. 财务自由：观察非固定工资收入与可投资资产对长期生活目标的支撑。

## 核心指标

| 指标 | 计算方式 |
| --- | --- |
| 家庭年收入 | 本人固定收入 + 配偶固定收入 + 其他收入 |
| 家庭年支出 | 生活 + 教育 + 赡养 + 偿债 + 储蓄 + 投资 + 保费 + 其他支出 |
| 年度结余 | 家庭年收入 - 家庭年支出 |
| 结余率 | 年度结余 ÷ 家庭年收入 |
| 家庭总资产 | 可用资金 + 自住资产 + 投资资产 + 已核实保单现金价值 |
| 家庭净资产 | 家庭总资产 - 实际负债余额 |
| 资产负债率 | 实际负债余额 ÷ 家庭总资产 |
| 房产占比 | 自住及使用资产 ÷ 家庭总资产 |
| 应急资金月数 | 随时可用资金 ÷（生活 + 教育 + 赡养支出）× 12 |

分母为 0 时，相应比例按 0 处理，避免形成无依据的无限值。

## 九项财务指标

| 阶段 | 指标 | 计算方式 | 报告参考值 |
| --- | --- | --- | --- |
| 财务安全 | 必要生活支出比率 | 必要生活年支出 ÷ 年收入 | < 50% |
| 财务安全 | 保障支出比率 | 保障型保费 ÷ 年收入 | ≥ 10% 参考 |
| 财务安全 | 财务安全比率 | 现金类资产 ÷ 必要生活年支出 | ≥ 50%，并结合 6 至 12 个月应急资金观察 |
| 财务独立 | 结余比率 | 年度结余 ÷ 年收入 | ≥ 30% |
| 财务独立 | 理财投资支出比率 | 储蓄及投资投入 ÷ 年收入 | ≥ 30% 参考 |
| 财务独立 | 负债比率 | 总负债 ÷ 总资产 | < 50% |
| 财务独立 | 财务独立比率 | 年收入 ÷ 年支出 | > 100% |
| 财务自由 | 资产规模比率 | 投资理财资产与已核实保单现金价值 ÷ 净资产 | ≥ 50% 参考 |
| 财务自由 | 财务自由比率 | 其他收入 ÷ 必要生活年支出 | ≥ 100% |

“其他收入”可能包含租金、分红、利息或临时性收入。财务自由比率形成正式结论前，必须由顾问核实收入性质、税费、稳定性与持续期限。

## 报告提示与四级风险结果

当前判断只是用于组织顾问讲解的启发式提示：

| 结果 | 触发原则 |
| --- | --- |
| 资料不足 | 收入、支出、资产或必要生活支出等核心数据不足 |
| 明确缺口 | 年度现金流为负、应急资金不足 3 个月、资产负债率达到 70% 以上，或存在确认未配置的家庭保障 |
| 需要关注 | 应急资金少于 6 个月、资产负债率达到 50%、房产占比超过 60%、结余率低于 30%，或保单初筛资料待补充 |
| 结构稳健 | 当前已录入资料未触发以上结构性风险，仍需顾问定期复核 |

报告不再生成家庭总分。九项指标仍分别显示“达标、关注、优先改善、待补充”，用于排列沟通顺序，不构成家庭评级或投资风险测评。

这些阈值不是统一行业标准，也不是保险产品推荐、投资适当性结论或收益承诺。顾问可以修改“综合判断”和“建议的下一步”文字。

## 家庭保单初筛

保单页面用于第一层资料筛查。家庭成员包括本人、配偶，以及家庭资料中数量大于 0 的子女和父母；险种包括医疗险、重疾险、寿险、意外险和养老年金。

每位成员在每个险种下记录“是否配置”和“保额或年领取金额”：

| 配置状态 | 含义 |
| --- | --- |
| 已配置 | 家庭确认已有该险种，并继续填写保额 |
| 未配置 | 家庭确认当前没有配置该险种 |
| 待确认 | 尚未确认是否配置 |
| 不适用 | 当前成员不参与该险种盘点，不计入汇总 |

未配置显示为“明确缺口”；已配置但没有保额、以及待确认项目显示为“资料待补充”；已配置并填写保额只表示完成基础录入。医疗保额不能单独证明保障充分，后续取得完整保单后仍需核对免赔额、报销范围、医院范围、续保条件、保险责任、期限和除外事项。

保单初筛不参与九项财务指标判断，只用于家庭四级风险结果、报告中的保障提示和行动顺序。

## 报告组成

1. 家庭财务总览与三阶段目标；
2. 家庭收入与支出分析；
3. 家庭资产与负债分析；
4. 九项家庭财务指标；
5. 家庭目标、成员险种保单初筛与 30 天执行建议。

## 资料状态

- 未勾选确认：报告显示“顾问填写草稿”；
- 顾问确认核心数据已与家庭核对：报告显示“家庭已确认”；
- 无论是否确认，报告仍需顾问复核后再对外使用。
