# 计算口径 MVP 0.1

所有金额统一使用“万元”，收入和支出使用“万元 / 年”。当前版本只做确定性计算，不调用 AI 推测家庭事实。

## 核心指标

| 指标 | 计算方式 |
| --- | --- |
| 家庭年收入 | 本人固定收入 + 配偶固定收入 + 其他收入 |
| 家庭年支出 | 生活 + 教育 + 赡养 + 偿债 + 储蓄 + 投资 + 保费 + 其他支出 |
| 年度结余 | 家庭年收入 - 家庭年支出 |
| 结余率 | 年度结余 ÷ 家庭年收入 |
| 家庭总资产 | 可用资金 + 自住资产 + 投资资产 + 已核实保单现金价值 |
| 家庭净资产 | 家庭总资产 - 实际负债余额 |
| 资产负债率 | 实际负债余额 ÷ 家庭总资产 |
| 房产占比 | 自住及使用资产 ÷ 家庭总资产 |
| 应急资金月数 | 随时可用资金 ÷（生活 + 教育 + 赡养支出）× 12 |

分母为 0 时，相应比例按 0 处理，避免形成无依据的无限值。

## 报告提示规则

当前判断只是用于组织顾问讲解的启发式提示：

1. 应急资金不足 6 个月：显示“应急资金仍需补足”；
2. 否则，房产占总资产超过 60%：显示“先改善家庭资产流动性”；
3. 其他情况：显示“家庭现金流保持稳定”。

这些阈值不是保险产品推荐、投资适当性结论或收益承诺。顾问可以修改“综合判断”和“建议的下一步”文字。

## 资料状态

- 未勾选确认：报告显示“顾问填写草稿”；
- 顾问确认核心数据已与家庭核对：报告显示“家庭已确认”；
- 无论是否确认，报告仍需顾问复核后再对外使用。
