# 家庭财务规划工具

面向保险顾问的电脑网页端家庭财务资料填写与图文报告工具。

在线体验：<https://nemoyang886.github.io/family-finance-planner/>

## 当前范围

- 保险顾问在电脑端填写家庭资料；
- 使用预选项、分步推进和即时反馈，降低填写负担；
- 本地自动保存草稿；
- 支持新建空白家庭档案；
- 实时计算家庭现金流、资产负债和应急资金；
- 按险种初筛本人、配偶、子女和父母是否配置，并录入保额；
- 使用“结构稳健、需要关注、明确缺口、资料不足”四级家庭风险结果，不生成家庭总分；
- 由顾问填写综合判断和下一步行动；
- 生成五页家庭财务规划报告书，覆盖总览、收支、资产负债、九项指标、家庭保单和执行建议；
- 报告同时提供数据表、结构图、参考值、顾问解释和资料状态；
- 支持下载完整高清长图，以及按 A4 分页打印或保存 PDF；
- 不包含后端、登录、云端客户库和具体产品推荐。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://127.0.0.1:5173/
```

## 检查

```bash
npm run typecheck
npm run build
```

计算公式和提示规则见 [docs/CALCULATIONS.md](docs/CALCULATIONS.md)。

## 数据说明

初始数据均为虚构示例。修改后的内容只保存在当前浏览器的 `localStorage` 中，清除浏览器数据会删除草稿。

请勿把当前纯前端版本作为真实客户资料的长期存储系统。正式上线前还需要加入身份验证、加密存储、权限控制、审计和备份。
