# 家庭财务规划工具

面向保险顾问的电脑网页端家庭财务资料填写与图文报告工具。

正式入口：<https://leo-hwp.cn/finance/>

旧版入口仍保留：<https://cw.leo-hwp.cn/>

## 当前范围

- 保险顾问在电脑端填写家庭资料；
- 使用预选项、分步推进和即时反馈，降低填写负担；
- 复用团小保账号登录与使用期状态；
- 草稿按账号保存在当前设备；
- 支持新建空白家庭档案；
- 实时计算家庭现金流、资产负债和应急资金；
- 按险种初筛本人、配偶、子女和父母是否配置，并录入保额；
- 使用“结构稳健、需要关注、明确缺口、资料不足”四级家庭风险结果，不生成家庭总分；
- 由顾问填写综合判断和下一步行动；
- 生成家庭财务安全分析报告，覆盖阶段定位、收支、资产负债、财务安全指数、家庭保障和规划建议；
- 报告同时提供数据表、结构图、参考值和客户可读的专业解读；
- 支持下载完整高清长图，以及按 A4 分页打印或保存 PDF；
- 不包含云端客户资料库和具体产品推荐。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://127.0.0.1:5173/
```

## 检查

```bash
npm run typecheck
npm run build
```

计算公式和提示规则见 [docs/CALCULATIONS.md](docs/CALCULATIONS.md)。

## 数据说明

初始数据均为虚构示例。修改后的内容按团小保账号保存在当前浏览器的 `localStorage` 中，清除浏览器数据会删除草稿。

请勿把当前本机草稿作为真实客户资料的唯一长期存储。后续如接入云端客户库，还需要补充加密存储、细粒度权限、审计和备份。
